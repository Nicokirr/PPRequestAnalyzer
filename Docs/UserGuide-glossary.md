# Terms

This is work in progress and will be completed soon.

### Licensed User (LU)

This is the official term for users create in EntraID and generating request on the platform. Any user is considered as a licensed user, even if the user has no licensed assigned. This consumption and it's limits is specific to each user (no pooling mechanism).

To simplify, this tool only refers to these as "User"

### Non-Licensed User (NLU)

This is the official term for service principals generating request on the platform. Any request generated by a service principal is pooled at the tenant level. The tenant limit depends on the Power Platform & Dynamics 365 licenses you have.

To simplify, this tool only refers to these as "Integrations"
