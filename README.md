# PPRequestAnalyzer
The purpose of this tool  is to provide detailed views on the consumption of APIs request on a given Power Platform tenant. The package includes : 
- A PowerBI report to analyse all data
- A Power Platform solution with X Power Automate cloud flows to automate the collection of raw data from the admin portal

# Disclaimer 
This is **NOT** a Microsoft supported tool, but a side project created to help the community better understand API consumption in a given tenant. This tool is supported on "best effort" only, with no SLAs
